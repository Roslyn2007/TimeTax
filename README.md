# ⏱️ TimeTax: Escape the Temporal Void

TimeTax: Escape the Temporal Void — это атмосферная 2D-платформенная аркада с элементами головоломки, где игроку предстоит преодолеть пять уникальных уровней, собирать монеты, избегать врагов и ловушек, и успеть выбраться через выходную дверь до того, как истечет время. Каждый уровень вводит новые механики: от простых патрулирующих врагов до порталов, конвейеров, исчезающих платформ и интеллектуальных врагов с ИИ на основе алгоритма A*.

---

## 🎮 Игровой процесс

В главном меню представлены три опции:

| Опция | Описание |
|-------|----------|
| ▶️ START GAME | Начать новую игру с первого уровня |
| 🔧 OPTIONS | Настройки звука (включить / выключить) |
| 🚪 QUIT | Выйти из игры |

### 🏃 Режим: Платформенная аркада

| Параметр | Значение |
|----------|----------|
| Количество уровней | 5 |
| Размер экрана | 800 × 480 пикселей |
| Управление | WASD / стрелки — движение, Space — прыжок, ESC — пауза, R — рестарт уровня, ENTER — подтверждение |
| Цель уровня | Собрать необходимое количество монет и дойти до выходной двери |
| Ограничение | Ограниченное время на каждый уровень |

**Основные правила:**
- Двигайтесь по платформам, прыгайте через пропасти, собирайте монеты.
- Избегайте врагов и шипов — столкновение отнимает время.
- Соберите достаточно монет — выходная дверь откроется.
- Дойдите до двери до истечения времени — уровень пройден.
- Если время закончится — игра окончена.

---

## 📊 Цели уровня

На каждом уровне у вас есть определённая цель:

- Собрать необходимое количество монет (от 5 до 9 в зависимости от уровня)
- Достичь выходной двери после сбора всех монет
- Управлять временем — золотые монеты добавляют 10 секунд, обычные — 5 секунд

## 🚧 Механики и препятствия

С каждым новым уровнем появляются новые элементы:

| Элемент | Внешний вид | Описание |
|---------|-------------|----------|
| 👾 Враги | Красные существа с глазами | Патрулируют платформы в заданном диапазоне. Столкновение отнимает 5 секунд. |
| 🧠 Умные враги | Красные существа (с 3-го уровня) | Используют алгоритм A* для преследования игрока. Имеют поле зрения, угол обзора и память. |
| 🔺 Шипы | Тёмно-красные пики | Стоят на платформах. Столкновение отнимает 8 секунд. |
| 🏭 Конвейеры | Голубые / бирюзовые полосы | Двигают игрока в направлении стрелки. |
| 🌀 Порталы | Фиолетовые пульсирующие прямоугольники | Телепортируют игрока в целевую точку. Перезарядка 1.5 секунды. |
| ⏳ Исчезающие платформы | Серо-голубые платформы | Исчезают через 5 секунд, появляются через 2 секунды. |
| 💰 Монеты | Золотые / жёлтые пульсирующие | Обычные добавляют 5 секунд, золотые — 10 секунд. |
| 🏁 Чекпоинты | Флаги (серые / зелёные) | Точки возрождения при падении в пропасть. |
| 🚪 Выходная дверь | Красная / зелёная | Открывается после сбора всех монет. |

| Опция | Действие |
|-------|----------|
| RESUME | Продолжить игру |

## 🏆 Система очков

За прохождение уровня начисляются очки:

| Компонент | Формула |
|-----------|---------|
| Базовые очки | Монеты × 100 |
| Бонус времени | Оставшиеся секунды × 10 |
| Множитель | ×3 (время > 30с), ×2 (время > 10с), ×1 (иначе) |

Итоговый счёт суммируется между уровнями.

## 💾 Сохранение прогресса

- Прогресс не сохраняется между запусками — каждая новая игра начинается с первого уровня.
- Внутри одной игровой сессии прогресс прохождения уровней сохраняется.
- Можно перепройти текущий уровень клавишей **R**.

## 🧠 Архитектура

Проект построен на паттерне **MVC** (Model-View-Controller):

- **Model** — изолирована от фреймворка MonoGame. Содержит всю игровую логику, физику, ИИ, управление временем. Может быть извлечена без переписывания.
- **View** — получает данные от Model через паттерн **Observer** (события). Не опрашивает модель в игровом цикле. Не имеет прямых вызовов отрисовки из контроллера.
- **Controller** — взаимодействует только с Model. Не имеет ссылок на View.

Связь через Observer: Model вызывает события (`TimeChanged`, `CoinsChanged`, `PlayerMoved`, `LevelStarted` и т.д.), на которые подписываются View-классы.

Принципы: **SOLID**, **DRY**, **KISS**. Каждый класс отвечает за одну задачу. Нет дублирования кода. Используются наследование, полиморфизм, инкапсуляция.

## 🎯 Уникальные алгоритмы

- **A* Pathfinding** — собственная реализация алгоритма поиска пути с оптимизациями: упрощение пути (line of sight), приоритетная очередь, поиск ближайшей проходимой точки.
- **QuadTree** — собственная реализация пространственного разбиения для оптимизации коллизий (10 объектов на узел, макс. глубина 5).
- **SmartEnemy AI** — конечный автомат с состояниями Patrol, Chase, Search, Return. Использует A* для навигации, имеет поле зрения с углом обзора, память преследования, обнаружение застреваний с автоматическим прыжком.
